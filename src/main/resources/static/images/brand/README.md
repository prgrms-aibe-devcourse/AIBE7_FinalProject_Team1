# PastPort 브랜드 파일

| 파일 | 용도 | 크기 / 배경 |
| --- | --- | --- |
| `pastport-logo-v1.png` | 웹 헤더, 로그인, 관리자, 발표자료의 가로 로고 | 2172 × 724 / 투명 |
| `pastport-symbol-v1.png` | 발표자료, 프로필 등 정사각형 심볼 | 1254 × 1254 / 투명 |
| `pastport-share-v1.png` | 링크 공유 대표 이미지, 발표자료의 서비스 소개 | 1730 × 909 / 밝은 배경 |
| `../../favicon.svg` | 브라우저 탭의 작은 아이콘 | SVG / 밝은 바탕 |

표기는 **PastPort**로 사용한다. 가로 로고와 심볼은 원래 비율을 유지하고 밝은 바탕에서 사용한다.
발표자료에는 PNG 파일을 직접 삽입할 수 있다. 공유 이미지는 웹페이지 내용과 같은 소개 문구를 사용한다.

파비콘은 작은 크기에 맞춰 단순화한 SVG이며 외부 이미지나 폰트에 의존하지 않는다.
헤더 로고와 발표용 PNG의 픽셀을 변환한 파일은 아니다.

## 공유 미리보기 적용 범위

`index.html`에 서비스 공통 Open Graph / Twitter 카드 메타정보가 있다.
관리자·이메일 인증 페이지에는 공통 공유 카드를 추가하지 않는다.
메타정보에는 현재 계정, 내 판매글, 이메일 인증 결과 등 개인별 정보가 포함되지 않는다.

현재는 로컬 확인을 위해 이미지 경로가 `/images/brand/pastport-share-v1.png`다.
배포 주소를 정하면 `index.html`의 **og:image / twitter:image** 두 값을
실제 배포 주소로 시작하는 HTTPS 절대 주소로 바꾼다. 필요하면 같은 배포 주소로 `og:url`과 canonical도 정한다.
아직 도메인이 정해지지 않아 임의의 운영 주소는 넣지 않았다.
외부 메신저의 실제 링크 미리보기 검증은 공개 배포 후 진행한다.

## 제작 기록

가로 로고와 PNG 파생 이미지는 내장 `image_gen` 도구로 제작했다. 실행 시 API 키를 별도로 사용하지 않았다.
파비콘 SVG는 기존 SVG 파일을 코드로 수정했다.

심볼·공유 이미지의 생성 프롬프트는 같은 폴더의 `generation-prompts.json`에 기록했다.
